# SIQ Technologies Website

Free GitHub Pages website.

## Files
- `index.html` = website content
- `style.css` = website design

## GitHub Pages setup
1. Create repository: `yourusername.github.io`
2. Upload `index.html` and `style.css`
3. Go to Settings > Pages
4. Source: Deploy from a branch
5. Branch: main / root
6. Save

## Custom domain
Go to Settings > Pages > Custom domain and enter your domain.

## Edit before publishing
Replace:
- `contact@yourdomain.com`
- phone number
- Formspree form ID
- company name if needed
